# ReadMe

#### Versión Antigua (estructura desactualizada)

Repositorio usado en la ayudantía 04 el día 24 de Septiembre del 2026 para el curso IIO422: Hidrología

Intrucciones:

0. Cree y acceda a su directorio de trabajo mediante la consola Git Bash.

1. Clone el directorio disponible en https://github.com/MoranVargas/IIO422_Ayudantia04 (git clone)
    - Crear una rama con el nombre de la estación de la forma git checkout -b Código_BNA

2. Siguiendo la estrucuta, cree un script en R con el cual debera realizar:
    - Análisis exploratorio de la base de datos asiganda.
    - Análisis de de homogeneidad y estacionariedad.
    - Nombrarlo de la forma “Apellidos.R”
3. Elaborar un mini informe en formato pdf mediante Quarto en la carpeta correspondiente.
4. Realizar un git commit con un mensaje adecuado y subir su trabajo con git push.
5. Elborar un pull request con una descripción del trabajo realizado para la estación.
